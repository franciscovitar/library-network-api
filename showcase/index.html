    02 / UNDER THE HOOD

    La complejidad está
    debajo de la superficie.

    El simulador enseña las reglas. La implementación original las hace cumplir con transacciones, bloqueos, restricciones SQL y pruebas concurrentes.

    01

    Transacciones atómicas

    La solicitud, el traslado, el historial y la clave de idempotencia confirman juntos o se revierten juntos.

    sessionmaker.begin()
    02

    Bloqueos por fila

    Las solicitudes rivales revalidan el estado después de adquirir bloqueos en un orden estable.

    SELECT … FOR UPDATE
    03

    Integridad en la base

    Un índice único parcial impide dos préstamos no terminales para el mismo ejemplar.

    UNIQUE WHERE status IN (...)
    04

    Reintentos seguros

    La misma clave y cuerpo reutilizan el resultado. La misma clave con distinto contenido obtiene un conflicto.

    Idempotency-Key · 409

    El backend es un monolito modular: API → comandos → dominio → PostgreSQL. Un producto complejo no necesita microservicios para ser serio.
