# Library Network API

A focused backend engineering portfolio project: reliable interlibrary lending with **Python, FastAPI and PostgreSQL**.

**Status:** initial repository setup; implementation is proposed on a feature branch. **Not production-ready.**

The first release will demonstrate a complete interlibrary loan lifecycle, transactional integrity, concurrent-request safety, idempotency and reproducible automated tests using synthetic data.
